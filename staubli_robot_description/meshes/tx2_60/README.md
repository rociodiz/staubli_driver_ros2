# Meshes for TX2-60 series

## TX2-60 (standard, short arm)

Use the plain `link_*` files (no suffix). Note: the standard (short) `link_2`
and `link_4` are only available as STL, so `meshes.yaml` uses STL for both the
visual and collision geometry of those two links.

## TX2-60L

Use `link_*_L.*` files when present.


## TX2-60L-med

Use `link_*_L_med.*` or `link_*_L.*` files when present, if both are present, use the `*_L_med.*0` ones.
